# Goalify 技能精简规格

## 目标

让 `goalify` 只负责把已澄清工作封装为边界清楚的自主目标，减少对最新模型已经具备的规划和执行能力的重复教学。

## 已确认行为

- 仅在用户明确要求或选择自主运行时触发。
- 正式规格是优先事实来源，但快速流程可以直接采用对话、问题单、分支和拉取请求中的已确认事实。
- 用户已明确终点时不重复询问；终点缺失或不可验证时才澄清。
- 保留 PR Ready、深度评审收敛、明确授权的合并和自定义终点。
- 选择深度评审收敛即授权为达到收敛而重复运行深度评审。
- 自主运行不能批准架构设计；出现新的产品范围或实质性架构决定时停止并交回用户。
- 目标只保留目标、权威事实与约束、终点与停止条件、交接，不预先规定实现切片。
- Codex 在能力可用时直接启动目标；Claude Code 或不具备启动能力的环境输出可粘贴文本。

## 非目标

- 不修改 `/goal` 运行机制。
- 不修改 `deep-review`、`incremental-impl` 或其他技能的内部流程。
- 不增加模型行为评测。
