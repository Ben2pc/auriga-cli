## Toolchain (本仓库验证栈)

> A1 调研所得的既成事实，不是本次功能的实现决策。只填本契约 VAL 实际用到的类别。

| Category (类别) | This repo's concrete tool (本仓库具体工具) |
|---|---|
| `repo-check` | `node:test` 驱动的技能清单、模板、引用和文件内容契约测试 |
| `build` | TypeScript 构建与目录生成器 |
| `e2e-cli` | `npm run test:e2e` 的真实安装包与插件安装验证 |
| `manual` | 对照用户确认方向、现有两项技能与参考技能的人工审查 |

## Assertions (断言)

### VAL-ASSET-001
- **Behavior (行为)**: Auriga 只发布一个自有的 `test-driven-development` 入口，外部同名技能不再作为锁定或预设资产，独立 `test-designer` 不再发布。
- **Tool (工具)**: repo-check
- **Evidence (判据)**: 技能目录、插件清单、外部技能锁和生成目录中不存在两个并行入口或残留的外部核心依赖。

### VAL-TDD-001
- **Behavior (行为)**: 新技能要求在存在有效测试接缝时，以最小且原因正确的失败证据约束目标行为，再实现最小纵向切片并回归验证。
- **Tool (工具)**: manual
- **Evidence (判据)**: 技能能独立说明失败证据、最小实现和回归验证的边界，但不包含“先有实现就必须删除重来”的绝对规则。

### VAL-TDD-002
- **Behavior (行为)**: 新技能优先验证公共接口上的可观察行为，选择最低有效测试层级，并只在系统边界模拟外部依赖。
- **Tool (工具)**: manual
- **Evidence (判据)**: 技能保留行为测试、测试接缝、纵向小切片和边界模拟原则，不要求用户逐次确认接缝。

### VAL-TDD-003
- **Behavior (行为)**: 新技能拒绝没有独立行为价值的纯文本与实现细节断言，同时允许对机器协议、稳定文件格式和用户可见文本契约进行测试。
- **Tool (工具)**: manual
- **Evidence (判据)**: 技能明确区分低价值措辞匹配与真实文本契约，且不会因测试驱动开发流程本身要求增加无意义用例。

### VAL-FLOW-001
- **Behavior (行为)**: 该断言已撤销，不参与最终验收。
- **Tool (工具)**: manual
- **Evidence (判据)**: 父级覆盖映射不再引用该断言。

### VAL-MAP-001
- **Behavior (行为)**: 每条验收断言定义要证明的行为，不与单个验证用例一一对应；实现阶段先按 `Tool` 选择验证方式，再按风险展开为一个或多个必要用例，测试类断言可以对应多个测试用例。
- **Tool (工具)**: repo-check
- **Evidence (判据)**: 新技能明确区分验收断言、验证用例和测试用例，不会把单条 VAL 机械收缩成单个 case。

### VAL-FLOW-002
- **Behavior (行为)**: 工作流模板和保留技能对统一测试入口的引用一致，完成前验证与拉取请求测试质量审查继续承担各自的事后兜底职责。
- **Tool (工具)**: repo-check
- **Evidence (判据)**: 双语模板和技能引用不存在 `test-designer` 或外部技能路径残留，也没有把完成验证或事后审查职责重复写入新技能。

### VAL-REL-001
- **Behavior (行为)**: 用户可见的技能集合变化同步反映在命令行版本、插件版本、双语说明和生成目录中。
- **Tool (工具)**: build
- **Evidence (判据)**: 版本、目录、清单、帮助内容和文档对统一技能的归属与安装方式没有矛盾。

### VAL-REL-002
- **Behavior (行为)**: 安装或升级插件不会自动扫描、修改或删除以前独立安装的外部测试驱动开发技能。
- **Tool (工具)**: e2e-cli
- **Evidence (判据)**: 真实插件安装成功，既有独立技能与锁文件保持不变；双语说明要求内部团队人工清理旧副本。

### VAL-RISK-001
- **Behavior (行为)**: 精简、内化和删除旧入口后的兼容风险、观察信号与恢复条件具有长期记录。
- **Tool (工具)**: repo-check
- **Evidence (判据)**: 正式评审记录包含旧副本遮蔽、实现者盲区与约束过轻等风险，并分别给出何时加强规则或恢复外部能力的条件。

### VAL-STATE-001
- **Behavior (行为)**: 长期总规范和评审索引记录两项技能合并评审后的处置状态，并继续把未执行的模型评测与工程处置结论分开表达。
- **Tool (工具)**: repo-check
- **Evidence (判据)**: 长期状态矩阵具有当前子项链接、唯一处置结论和模型评测未执行说明，不把工程实现证据替代为模型评测证据。
