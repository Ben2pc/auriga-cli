# code-simplify 精简验收契约

- **VAL-CS-001**：技能只在明确的代码级简化、重构、清理、代码质量反馈处理或目录普查任务中触发，不把普通缺陷诊断纳入触发描述。
- **VAL-CS-002**：主文件明确区分代码内部简化、架构边界调整、缺陷修复和行为变更。
- **VAL-CS-003**：主文件保留偶然发现问题时先报告并取得用户授权的规则。
- **VAL-CS-004**：主文件以行为保护、真实维护成本和最小连贯改动作为核心执行依据，不包含固定代码规模阈值。
- **VAL-CS-005**：目录或模块普查先产出排序清单并由用户选择，不直接批量修改。
- **VAL-CS-006**：`language-examples.md` 被删除，所有引用同步移除。
- **VAL-CS-007**：重构手法参考继续保留，并被描述为按需读取的提醒列表。
- **VAL-CS-008**：主文件不再包含独立的验收清单、自我辩解、红旗或反模式章节。
