# code-simplify 精简规范

## 背景

现有 `code-simplify` 同时包含核心执行边界、基础重构教学、固定阈值、重复检查清单和面向弱模型的自我纠偏提示。新一代模型已经掌握通用重构知识，这些内容增加上下文和流程负担，却没有形成更可靠的代码简化结果。

## 目标

- 保留代码级简化与架构调整、缺陷修复之间的边界。
- 保留偶然发现坏味道时的用户授权门禁。
- 以行为保护、真实维护成本和最小连贯改动指导执行。
- 保留目录或模块普查能力，但只在用户明确要求或确认后执行。
- 保留重构手法参考作为按需提醒列表。

## 非目标

- 不教授模型基础重构语法或语言级改写技巧。
- 不使用固定行数、嵌套层数或重复次数判定坏味道。
- 不把验收清单、自我辩解、红旗和反模式作为重复软约束。
- 不在本轮修改重构手法目录的覆盖范围。

## 决定

- 删除 `references/language-examples.md`。
- 大幅精简主文件，仅保留边界、授权、核心约束、执行流程、普查模式和技能关系。
- 继续保留 `references/smells-and-refactorings.md`，并明确它是按需读取的提醒列表。
