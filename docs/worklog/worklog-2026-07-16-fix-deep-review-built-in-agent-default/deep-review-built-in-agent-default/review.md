## 接受并修复

### 测试契约没有要求全部条件同时成立

测试质量与技能插件质量审查者发现同一根因：`VAL-DR-AGENT-003` 要求四项行为同时成立，但原断言分别使用正则分支，只需命中其中一项就会通过。

处理：拆成四条独立断言，分别保护“不切换外部 Agent”“不停止内置评审”“不启动无法强制只读的外部进程”“记录审查缺口”。

### 长期总规范写死插件补丁版本

文档同步审查者发现总规范仍记录 4.0.5，而本次双运行时清单已经升级。

处理：总规范改为引用 Claude Code 与 Codex 清单的当前一致版本，不再随每次插件载荷修订维护精确补丁号。

## 未按建议修改

安全审查者建议在缺少逐 Agent 权限限制时停止内置评审。这与用户明确确认的产品行为冲突，因此不恢复停止分派或自动切换外部进程。

保留并加强的边界：内置 Agent 继承主编排只读策略，使用平台原生隔离与权限边界；宿主提供任务级只读模式或更细粒度限制时必须启用；只有用户明确要求的外部进程才额外要求可执行的进程级只读边界。真实宿主隔离能力属于平台能力，不在这个纯技能文本 PR 中伪造集成证据。
