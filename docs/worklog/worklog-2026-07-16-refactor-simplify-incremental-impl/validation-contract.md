# Incremental Impl 技能验证契约

| ID | 行为契约 | 验证证据 |
|---|---|---|
| VAL-IMPL-001 | 技能消费已确认的需求、架构和计划，不重新决定上游边界。 | 技能契约测试。 |
| VAL-IMPL-002 | 完整实施单元独立交付连贯需求结果或合法迁移状态，并包含实现、行为保护和必要配套变化。 | 技能契约测试。 |
| VAL-IMPL-003 | 单元按需求结果、技术不变量、独立验证和合法中间状态划分，不按文件、行数、提交或写入者划分。 | 技能契约测试。 |
| VAL-IMPL-004 | 技能不再包含 XS～XL 分档、差异行数阈值或最低并行代理数量。 | 负面契约测试。 |
| VAL-IMPL-005 | 默认单写者，并行要求文件所有权、输入输出和依赖独立。 | 技能契约测试。 |
| VAL-IMPL-006 | 模型与推理强度默认继承，运行时支持且确有需要时可以覆盖。 | 技能契约测试。 |
| VAL-IMPL-007 | 并行写入使用原生工作树、主代理预建工作树或退回串行。 | 技能契约测试。 |
| VAL-IMPL-008 | 派发数据包包含目标、来源、所有权、依赖、验证和证据。 | 技能契约测试。 |
| VAL-IMPL-009 | 只有委派写入需要精简交接；内联实现不生成固定模板。 | 技能契约测试。 |
| VAL-IMPL-010 | 提交遵循语义边界，不强制一个实施单元对应一个提交。 | 技能契约测试。 |
| VAL-IMPL-011 | 双语工作流入口和插件自述与新职责一致。 | 仓库契约测试。 |
