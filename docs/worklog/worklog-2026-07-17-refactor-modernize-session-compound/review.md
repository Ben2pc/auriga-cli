# Session Compound Modernization — Review（会话复利技能现代化 — 评审）

## Conclusion（结论）

主结论：**精简**。

`session-compound` 继续保留。它把一次或多次真实 Agent 工作转成可追溯的执行证据、使用洞察和人工选择的长期候选，承担跨会话聚合、独立评估和持久报告职责；但强制候选数量、无条件生态搜索、单会话限制和不可信的技能调用统计已被删除或替换。

## Failure Mode（失效模式）

- 单次会话中的偶发问题被包装成必须长期沉淀的新规则。
- 已经被现有资产吸收的用户反馈继续产生重复候选。
- 跨会话反复摩擦无法被单会话报告识别，建议缺少趋势证据。
- 技能读取被错误报告为零调用，导致执行评估遗漏真实参与的技能。
- 非零工具退出被直接解释为浪费，混淆预期失败测试与真实异常。
- 报告暴露长会话标识、复制原始记录或让分析 Agent 直接修改网页模板。

## Model Generation Assessment（新模型判断）

新模型能够从结构化会话切面归纳模式并提出建议，不需要固定候选数量、固定分类配额或每次都搜索外部生态。它们仍不能仅凭上下文窗口可靠完成跨数百会话的增量缓存、覆盖率计算、证据预算、隐私边界和确定性报告渲染，这些机制与持久产物必须保留。

本轮没有把 GPT 5.6 Sol 与 Fable 5 的行为评测作为验收项；结论来自当前实现、真实 Codex 与 Claude Code 会话报告、协议职责和人工报告审查。

## Retained Contracts（保留契约）

- 单会话复盘与最近 30 天洞察由用户显式选择，一次只生成一份报告。
- 单会话继续保留独立评估；跨会话模式必须由多个独立会话支持。
- 缓存只保存有界结构化切面，原始会话不进入长期缓存。
- 报告披露覆盖率、未分析数量、证据限制和可读追溯索引。
- 长期候选生成前核对当前资产，零候选是正常结果，资产修改仍需用户确认。
- Codex 与 Claude Code 的历史、缓存和报告保持隔离。

## Removed Constraints（删除约束）

- 强制生成 3–8 条沉淀候选及候选数量下限。
- 每次报告都执行生态搜索。
- 只分析当前单次会话的模式限制。
- 把技能读取缺失解释为未使用任何技能。
- 把全部非零退出自动解释为浪费。
- 晦涩的英文直译标题和正文直接展示长会话标识。

## Cost and Recovery Signal（成本与恢复信号）

新增的会话清单、缓存和确定性渲染提高了维护面，但把语义模型调用限制在增量预算内，并让大规模历史分析可持续。若缓存损坏频繁、跨会话聚合持续遗漏近期重要模式、报告生成成本超过节省的重复分析成本，或两种模式长期无人使用，应基于真实数据收缩缓存协议或重新评估近期洞察模式，不恢复固定候选配额。

## Deep Review Result（深入评审结果）

PR #193 的首次深入评审后修复了确认的阻塞和高优先级问题，并在最终提交中移除一处无效赋值。最终验证包括 524 项仓库测试、68 项分析器测试、22 项近期洞察管线测试、20 项会话指令测试、全部 Git 守卫、两套官方技能校验，以及真实 Codex 与 Claude Code 单会话和跨会话报告的人工检查。PR 于 2026-07-17 合并，提交为 `71651b7bd00f25dc1a952d0c5173de265523fd48`。
