- **关联**：VAL-FIELD-NAMING-004、VAL-SCAN-FIRST-COLUMN-004、VAL-REVISION-001、VAL-DECISION-PAGE-003、VAL-WRITING-SCOPE-004、VAL-NAVIGATION-002、VAL-LONG-RUNNING-001、VAL-MODEL-TYPE-004、VAL-SPEC-SUMMARY-003、VAL-SPEC-DETAIL-004、VAL-SPEC-SOURCE-001、VAL-VALIDATION-CONTRACT-001。
