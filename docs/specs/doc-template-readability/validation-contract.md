# 验收契约 — 规格与架构设计模板可读性

> 与 spec.md 配套：spec.md 写为什么做、做成什么样；本文件写什么算通过。一条验收不等于一个测试用例。
> 本文件按 spec.md 2.3.5 的写法组织（每个叶子一张表），它本身也是新写法的样例。

## 代表性验收路径

- **仓库检查**：逐条核对改写后的模板和两份 `SKILL.md`；字段名、表头和旧约定用搜索确认，篇幅用字节数确认。
- **样例重写评估**：模板改完后，各起一个全新上下文、只读的 Agent，只给新模板、新技能和样本：
  - 架构设计：`mooku_backend/docs/long-running-specs/service-platform/` 的规格与原设计，按新模板重写设计；
  - 规格：`mooku_backend/docs/worklog/worklog-2026-10-14-feat-series-selection/` 的规格，加上飞书产品需求文档“选剧换剧”，按新模板重写规格。
  产物写到临时目录；主代理逐项度量下表中标为“样例”的断言，并把决策页和要点页交给 Ben 抽读。
