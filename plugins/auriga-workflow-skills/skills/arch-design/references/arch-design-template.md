# `arch_design.md` 模板

`arch-design` 的 C3 闸门触发时,把下面的模板块复制到 `docs/specs/<topic>/arch_design.md`,逐个替换 `<占位符>`。

**用法约定**
- **章节标题保持原样**(英文锚点 + 中文提示)——下游工具和审查者按英文锚点定位。
- **正文用对话所用的语言写**(中文对话就写中文正文)。
- 每节下面的 `>` 引用块是写作提示,落稿时**删掉**。
- 没内容的节不要留 `TBD` / 占位符——要么写实,要么删掉整节(`Open Questions` 除外)。
- **能用图说清的,优先配图**——目录树、模块依赖图、数据流图对人类 reviewer 比大段文字友好。模块关系图用 Mermaid(GitHub 等可直接渲染),目录结构用 ASCII 树。

---

````markdown

> 这次设计要解决什么。新功能:一句话引用 spec 的目标。既有系统升级:写下 A3 命名的那个结构问题——它就是验收标准。
> 然后写当前架构 / 接入面:具体到文件路径、模块、依赖方向、数据流,不用形容词。
````
